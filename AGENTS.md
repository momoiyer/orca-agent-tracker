# This repository

Read README.md and HANDOFF.md. This project owns only local agent observability: dashboard, collectors, lifecycle hooks, and service integration. Personal working rules, reusable development skills, and specialist-role installation belong to the independent ai-config project.

- Python 3.11+ standard library; frontend assets are buildless HTML/CSS/JavaScript. Run python3 -m unittest discover -s scripts -p 'test_*.py' and node --check dashboard/app.js for relevant changes.
- Never import a sibling ai-config checkout or maintain a second copy of its canonical policy/role definitions. Read installed client configuration for observation.
- Preserve current hook/settings entries and private activity data. Preview installers before activation; never bypass Codex hook trust.
- Lifecycle events are observations, not proof of liveness. Preserve stale-state suppression, source failures, identity joins, and parent/child separation.
- Keep the legacy hook marker, service label, and state path compatible unless an explicit migration is designed and tested.
- Never put real task labels, credentials, project paths, activity DBs, private settings, or live screenshots into fixtures or Git. Bind the dashboard to loopback and preserve its read-only API boundary.
